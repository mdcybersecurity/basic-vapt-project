# Basic VAPT Project
This project demonstrates basic VAPT (Vulnerability Assessment and Penetration Testing) using Nmap.

## Tools Used
- Nmap 
## Objective
To perform reconnaissance and identify open ports on a target system.

## Command Used
nmap scanme.nmap.org

## Result
The scan identified multiple open ports including:
- 22 (SSH)
- 80 (HTTP)
- 25 (SMTP)

## Disclaimer
This project was performed on a legal test target provided by Nmap.
